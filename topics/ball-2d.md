### 8-A. 2D ball balancing (공 위치 → 플레이트 2 축 기울기)

**좌표 · 단위 (한 번 정하고 바꾸지 않는다)**
- 플레이트 좌표 `(x, y)` [mm], 원점 = 플레이트 중심, 축 방향은 `docs/frames.md` 의 그림 하나로 고정한다
- 센서 raw (카메라 픽셀 · 터치패널 ADC) → mm 변환은 `src/sensing/calib.py` 한 곳에만 둔다. 카메라는 homography 보정값을 파일로 저장해 커밋한다
- 서보 명령 [deg] → 플레이트 기울기 [deg] 는 링키지 때문에 비선형이다. 변환 함수와 측정한 보정표를 함께 둔다

**지표 (보고서의 표 머리와 같은 이름을 쓴다)**
- 정상상태 오차 RMS [mm] — 목표점 유지 10 s 구간
- 정착시간 [s] — 계단 목표 변경 후 공이 ±5 mm 원 안에 머무르기 시작한 시각 (기준 원 반지름은 §0 에서 고정)
- 외란 복귀시간 [s] — 재현 가능한 외란 (예: 정해진 크기 · 길이의 펄스 기울기를 제어 출력에 더함) 후 복귀. 손으로 미는 외란은 크기가 매번 달라 비교에 쓰지 않는다
- 원 궤적 추종 오차 RMS [mm] — 반지름 · 주기 고정
- 루프 주기 실측 (평균 · 최대 Δt) — 「50 Hz 로 돌았다」 는 측정값으로만 말한다

**안전**
- 서보 각도 한계는 `hw/limits.py` 에만 둔다 (예: ±12°). 링키지가 걸리는 각도보다 작게
- 서보가 한계에 붙어 떨면 (stall) 전류가 커진다 — 2 초 이상 한계 유지 시 출력을 중립으로 되돌리는 감시를 둔다

**흔한 함정**
- 카메라 자동 노출 · 자동 화이트밸런스: 런마다 공 검출 임계가 달라진다 → 고정하고 실제 값을 로그에 남긴다 (§4-4)
- x · y 축 부호 또는 서보 배선이 뒤바뀜 → 한 축씩 열린 루프로 「+ 명령 → 공이 + 로 굴러감」 을 먼저 확인한다
- 소프트웨어 PWM 지터 → 하드웨어 PWM (또는 PWM 드라이버 보드) 사용, 지터를 측정해 기록한다
- 목표 변경 시 미분 킥, 서보 포화 중 적분 누적 (windup) — 둘 다 「측정치 미분」 · anti-windup 으로 다룬다
- 프레임 누락 · 처리 지연 → 프레임마다 타임스탬프를 남기고 `tools/check_log.py` 로 확인한다

**로그 필드 (최소)**: `t, tick, x_mm, y_mm, ref_x, ref_y, u_x_deg, u_y_deg, frame_ms`
