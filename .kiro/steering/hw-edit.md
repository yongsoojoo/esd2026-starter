# 구동 코드를 다룰 때의 확인 목록 (Kiro 전용 보조 규칙)

이 파일이 적재되었다는 것은 지금 구동기 (서보 · 모터 · 레이저) 코드를 다루고 있다는 뜻이다.
규칙 본문은 `AGENTS.md` §3 하드웨어 안전이다. 아래는 그 규칙을 지키기 위해 **보고에 넣을 항목**이다.

1. 바뀐 한계 상수가 있는가 — 있으면 `hw/limits.py` 의 어느 값이 얼마에서 얼마로 바뀌는지 (계획 승인 대상)
2. 사람이 실행할 명령 한 줄 — 에이전트는 이 명령을 직접 실행하지 않는다
3. 정상이면 보일 동작과 즉시 전원을 끊어야 할 중단 기준
4. 첫 실행 조건 — 낮은 이득 · 좁은 각도 한계 · 바퀴 띄움 / 레이저 대신 LED 등
5. 실행 후 받을 로그 파일 이름과 `tools/check_log.py` 확인 명령
