# AI 사용 기록

이 파일은 **필수**다 (`AGENTS.md` §6-3). 에이전트와 일한 세션마다 한 줄을 추가한다. 보고서의 「AI 사용 고지」 는 이 표에서 만든다.

- **한 일**: 에이전트가 만든 것 · 고친 것 · 조사한 것 (파일 이름이나 커밋으로)
- **사람이 검토한 범위**: 사람이 직접 읽고 확인한 부분. 「전부 검토」 처럼 쓰지 말고 무엇을 어떻게 확인했는지 적는다
  (예: 「`ctrl/pid.py` 를 읽고 시뮬레이터 계단응답으로 확인」, 「표 2 의 수치를 로그와 대조」)
- 에이전트가 틀린 것을 사람이 잡았다면 그것도 적는다 — 그 기록이 다음 규칙 개정의 근거가 된다

| 날짜 | 사람 | 도구 · 모델 | 한 일 | 사람이 검토한 범위 | 회의록 |
|---|---|---|---|---|---|
| YYYY-MM-DD | <이름> | <예: Kiro · Auto> | <예: `tools/plot.py` 작성> | <예: 출력 그림을 로그와 대조> | `docs/meeting-notes/<파일>` |
